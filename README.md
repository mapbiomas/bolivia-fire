# 🔥 MapBiomas Fire Bolivia

This repository contains scripts, tools, and workflows for mapping burned areas in Bolivia as part of the **MapBiomas Fire** initiative.

The scripts support the processing, classification, and analysis of satellite imagery used to identify and map burned areas across the Bolivian territory.

For detailed information about the methodology, classification criteria, and processing workflow, refer to the official [MapBiomas Fire methodology](https://brasil.mapbiomas.org/metodo-mapbiomas-fogo/).

## 🚀 Prerequisites

- A **Google Earth Engine** account ([sign up here](https://earthengine.google.com/)).
- Basic familiarity with the Google Earth Engine Code Editor.

## 📂 Repository Modules

### 1. [Fire Landsat 30m (`fire_landsat_30m/`)](./fire_landsat_30m/README.md)

Workflows, notebooks, and methodological configurations for burned-area classification using 30-meter Landsat imagery. This module contains the procedures and parameters used for `collection_01` across the ecoregions of Bolivia.
